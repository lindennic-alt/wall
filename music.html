Search YouTube

Searching needs a free YouTube API key from Google, set up once. It allows about 100 searches a day.

  1. Open console.cloud.google.com, sign in, and create a project named “Music Hub”.
  2. Open YouTube Data API v3 and tap Enable.
  3. Go to APIs & Services › Credentials › Create credentials › API key.
  4. Edit the key. Under Application restrictions choose Websites and add . Under API restrictions choose YouTube Data API v3. Save.
  5. Copy the key and paste it here.

Search Spotify

Searching needs a free Spotify developer app, set up once. It takes about five minutes.

  1. On any device, open developer.spotify.com/dashboard, log in with your Spotify account and tap Create app.
  2. Name it “Music Hub”. For Redirect URI enter
  3. Tick Web API, agree to the terms and save.
  4. Open the app’s Settings, copy the Client ID and paste it here.
